## pagers — latest build

A Rust CLI for paginating and browsing large outputs: pipe anything
through `pagers` for a fast, keyboard-driven pager with search,
filters, and multiple view modes.

### Download

| Platform | Asset |
| --- | --- |
| Linux x86_64 | `pagers-x86_64-unknown-linux-gnu` |
| macOS Apple Silicon | `pagers-aarch64-apple-darwin` |
| Windows x86_64 | `pagers-x86_64-pc-windows-msvc.exe` |

### Quick start

```sh
cat huge.log | pagers
pagers --help
```
