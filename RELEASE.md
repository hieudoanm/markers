## markers — latest build

A Rust static site generator: write Markdown, run one command, get a
website — clean URLs, file-tree navigation, themes, a link graph, and
single-page `markers landing` sites. No Node.js, no runtime dependencies.

### Download

| Platform            | Asset                                |
| ------------------- | ------------------------------------ |
| Linux x86_64        | `markers-x86_64-unknown-linux-gnu`   |
| macOS Apple Silicon | `markers-aarch64-apple-darwin`       |
| Windows x86_64      | `markers-x86_64-pc-windows-msvc.exe` |

### Quick start

```sh
markers init ./docs
markers build ./docs
markers serve ./docs
```
